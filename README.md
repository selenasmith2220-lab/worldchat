# WorldChat — GitHub Pages Prototype

A GitHub Pages-friendly frontend for an international chat and Blind Date social website.

## Files

- `index.html` — all interface screens
- `style.css` — responsive visual design
- `script.js` — navigation, 15-second ad placeholder, demo chat, and Blind Date demo

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Important

This version is intentionally GitHub-only and therefore frontend/static.

The social sign-in buttons, real multi-user chat, persistent accounts, subscriptions, and ad-network integration are UI/demo placeholders. Those features require external services or server-side functionality when you are ready to make the platform genuinely multiplayer and monetized.

The 15-second screen is a placeholder; replace it with an ad format that your chosen advertising provider permits.
